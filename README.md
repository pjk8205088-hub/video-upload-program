# 동영상 업로드 프로그램

로컬 파일을 안전하게 업로드하고 정리하는 Upload Desk MVP입니다.

## 실행

```bash
npm start
```

브라우저에서 `http://localhost:3000`을 엽니다.

## 지원 범위

- MP4, MOV, WebM, MKV 파일 업로드
- 파일 드래그 앤 드롭 및 다중 선택
- 업로드 진행률 표시
- 업로드한 영상 목록, 검색, 최신순/오래된순 정렬
- 영상 삭제
- 로컬 `uploads/` 파일 저장 및 `data/videos.json` 메타데이터 저장

테스트는 `npm test`로 실행합니다.
