# 가정 및 미확정 사항

## 확정 가정

- 프로젝트명은 동영상 업로드 프로그램이다.
- 사용 환경은 Windows 데스크톱이다.
- 지원 SNS는 YouTube, 네이버, TikTok, Facebook, Instagram이다.
- 앱은 로컬 단일 워크스페이스를 대상으로 한다.
- 계정 연결 화면은 개발 모드에서 아이디·핸들을 저장하며 실제 연동은 OAuth로 교체한다.
- 쿠팡 화면은 그대로 복제하지 않고, 익숙한 커머스 관리자형 카드·목록 밀도와 레드 포인트만 참고한다.

## 확인이 필요한 내용

- 각 플랫폼에 실제 게시할 공식 API와 OAuth 앱 정보
- 계정별 제목·설명·해시태그 템플릿이 필요한지
- 예약 작업의 실패 재시도와 게시 결과 알림 정책
- 썸네일, 영상 변환, 플랫폼별 길이·용량 제한
- 팀 계정과 권한 관리 필요 여부

## 현재 진행 방식

외부 API 자격 증명이 없는 상태에서 임의의 SNS 로그인이나 자동 게시를 시도하지 않는다. 현재는 연결 계정·멀티 채널 작업·YouTube 체크 자동화·예약 큐를 완성하고, 실연동은 공식 API별 adapter 단계로 분리한다.
