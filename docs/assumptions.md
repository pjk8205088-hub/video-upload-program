# 가정 및 미확정 사항

## 가정한 내용

- 프로젝트명은 **동영상 업로드 프로그램**으로 확정한다.
- MVP 사용자는 한 대의 로컬 PC에서 동작하는 단일 관리자다.
- 지원 동영상 형식은 MP4, MOV, WebM, MKV다.
- 파일 1개당 최대 크기는 2 GB로 정한다.
- 외부 저장소와 로그인은 첫 단계에서 필요하지 않다.
- 영상 변환·썸네일 생성보다 업로드 성공과 파일 정리를 우선한다.

## 확인이 필요한 내용

- 실제 배포 대상이 로컬 앱인지 사내 웹 서버인지
- 다중 사용자와 팀별 공유가 필요한지
- 영상 상세 재생·다운로드가 MVP에 포함되는지
- 보존 기간, 파일 자동 삭제 정책이 필요한지
- 백업과 개인정보·저작권 관련 운영 정책

## 현재 진행 방식

확인되지 않은 항목은 로컬 단일 관리자·10 GB 표시 기준·원본 보존 기준으로 구현했다. 배포 환경이 정해지면 인증, 저장소, 제한값을 문서와 코드에 함께 갱신한다.
