# 동영상 업로드 프로그램 화면 목록

## 업로드 센터

- URL: `/`
- 접근 권한: 로컬 워크스페이스 관리자
- 목적: 업로드 시작, 진행률 확인, 저장된 동영상 관리
- 주요 컴포넌트: 사이드바, 로컬 저장공간 미터, 업로드 드롭존, 업로드 큐, 영상 목록
- 입력 요소: 동영상 파일 선택, 검색 필드
- 버튼: 동영상 선택, 정렬 토글, 삭제, 도움말
- API 연동: `GET /api/videos`, `POST /api/videos`, `DELETE /api/videos/:id`
- 이동 경로: 앱 진입 → 업로드 센터 → 목록 / 업로드 큐
- 빈 상태: 아직 업로드한 영상이 없다는 안내와 업로드 시작 링크
- 오류 상태: 토스트로 형식·용량·서버 오류를 안내
- 로딩 상태: 목록 조회 동안 기존 빈 상태가 유지되고, 업로드는 큐에 즉시 표시

## 업로드 큐 상태

- URL: `/`의 `#queueSection`
- 목적: 현재 진행 중인 파일을 확인
- 주요 컴포넌트: 파일명, 썸네일형 프리뷰, 진행률 바, 퍼센트/실패 상태
- 상태: 업로드 중, 완료, 실패

## 내 동영상 목록 상태

- URL: `/`의 `#library`
- 목적: 저장된 영상 조회·검색·삭제
- 주요 컴포넌트: 검색, 정렬, 영상 행, 상태 태그, 삭제 버튼
- 상태: 전체 목록, 검색 결과 없음, 데이터 없음

## 반응형 동작

- 860px 이하: 사이드바가 상단 내비게이션으로 바뀌고 목록의 부가 열을 숨긴다.
- 500px 이하: 업로드 카피와 드롭존을 세로로 쌓고 검색 영역을 전체 너비로 확장한다.
