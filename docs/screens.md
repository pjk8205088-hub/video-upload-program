# 동영상 업로드 프로그램 화면 목록

## Windows 데스크톱 업로드 센터

- URL: `/`
- 접근 권한: 로컬 워크스페이스 관리자
- 목적: 파일 업로드, 계정 연결, 멀티 채널 예약, 라이브러리 관리
- 주요 컴포넌트: Windows 타이틀바, 좌측 컨트롤 패널, 요약 카드, 업로드 드롭존, 계정 카드, 연결 맵, 예약 큐, 영상 목록
- 이동 경로: 앱 진입 → 업로드 센터 → SNS 계정 → 동시 업로드 예약 → 예약 큐
- 빈 상태: 원본 없음, 계정 없음, 예약 없음, 라이브러리 없음
- 오류 상태: 형식·용량·서버 오류를 토스트로 안내

## SNS 계정

- URL: `/`의 `#accounts`
- 목적: YouTube·네이버·TikTok·Facebook·Instagram 계정 연결 상태 관리
- 컴포넌트: 플랫폼 카드, 연결 버튼, 연결 해제 버튼, 계정 대상 칩
- 상태: 미연결, 연결됨, 여러 계정 연결

## 동시 업로드 예약

- URL: `/`의 `#campaign`
- 목적: 하나의 원본과 여러 계정을 연결해 같은 예약 시각으로 작업 생성
- 컴포넌트: SVG 연결 맵, 제목·설명·공개 범위·예약일 입력, 대상 계정, YouTube 체크리스트
- 상태: 원본 없음, 대상 없음, 연결 준비, 예약 등록 완료

## 예약 업로드 큐

- URL: `/`의 `#scheduled`
- 목적: 예약 작업과 계정별 전송 대기 상태 확인
- 컴포넌트: 작업 제목, 설명, 대상 계정 태그, 예약 시각, 상태

## 반응형 동작

- 1100px 이하: 연결 맵과 예약 폼을 세로로 쌓는다.
- 800px 이하: 좌측 패널을 축소하고 계정 카드·요약 카드를 재배치한다.
