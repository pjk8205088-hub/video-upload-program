# 화면 구성

## 슬롯 보드

상단 요약 카드와 1~10 슬롯 매트릭스가 먼저 보인다. 각 슬롯에는 고정 번호, READY/EMPTY 상태, 썸네일, 파일명, AI 제목, 교체·삭제가 있다.

## 계정 라우팅

SNS 계정 카드마다 번호 1~10 스위치가 있다. 해당 번호의 영상이 없으면 비활성화되고, 체크된 계정×슬롯은 현재 경로 칩과 예약 미리보기에 표시된다.

## 예약·캘린더

예약 폼은 AI 생성, 설명, 해시태그, 시각, 공개 범위를 제공한다. 예약 작업은 job별 진행률·상태·시도 횟수·재시도 버튼을 보여주며 월간 캘린더에 표시된다.

## 운영 패널

게시 통계, mock 댓글 답글·숨김 관리, 활동 로그, Windows 시작·업데이트 설정을 한 화면에서 확인한다.

## 계정 로그인 페이지

환경설정 아래에 Instagram, 네이버 클립, TikTok, Facebook 하위 메뉴를 둔다. 각 페이지는 서비스별 OAuth 방식, 요청 권한(scope), 연결 상태, 연결된 계정, 로그인 시작 버튼을 독립적으로 보여준다. 실제 OAuth 자격 증명이 없는 sandbox에서는 계정 식별자 입력 modal을 열고, 실서비스 전환 시 provider별 OAuth callback으로 교체한다.
