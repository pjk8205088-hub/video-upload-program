# 동영상 업로드 프로그램 기능 목록

## 동영상 업로드

- 목적: 원본 동영상을 로컬 라이브러리에 저장한다.
- 입력: 파일 선택, 드래그 앤 드롭.
- 처리: 확장자·MIME·크기 검증 후 스트리밍 저장.
- 출력: 업로드 큐, 진행률, 영상 목록.
- 우선순위: P0.
- 구현 상태: 완료.

## SNS 계정 연결

- 목적: 다섯 플랫폼의 업로드 목적지를 한 화면에서 관리한다.
- 입력: 플랫폼, 표시 이름, 아이디 또는 핸들.
- 처리: `POST /api/accounts`로 계정 메타데이터 저장.
- 출력: 플랫폼별 연결 상태, 연결 해제, 대상 선택 칩.
- 우선순위: P0.
- 구현 상태: 개발 모드 완료, OAuth 실연동 대기.

## 멀티 채널 업로드 맵

- 목적: 영상 하나가 여러 SNS로 전달되는 구조를 보여준다.
- 입력: 원본 영상과 선택한 계정.
- 처리: SVG 연결선으로 원본 노드와 계정 노드를 연결.
- 출력: 거미줄형 업로드 경로, 계정별 READY 상태.
- 우선순위: P0.
- 구현 상태: 완료.

## 예약 업로드 큐

- 목적: 여러 계정에 같은 콘텐츠를 동시에 예약한다.
- 입력: 제목, 설명, 공개 범위, 예약일, 대상 계정.
- 처리: `POST /api/campaigns`가 계정별 `queued` job을 생성.
- 출력: 예약 작업 목록과 계정별 전송 대기 상태.
- 예외: 원본·제목·예약일·대상 계정 누락.
- 우선순위: P0.
- 구현 상태: 완료.

## YouTube 자동 체크

- 목적: 반복 입력 항목을 자동 확인해 실수를 줄인다.
- 자동 체크: 제목, 설명, 카테고리, 공개 범위, 해시태그.
- 수동 체크: 썸네일, 아동용 콘텐츠 여부, 재생목록.
- 우선순위: P0.
- 구현 상태: 완료.

## 로컬 저장공간·영상 목록

- 목적: 저장량과 파일 상태를 확인하고 검색·정렬·삭제한다.
- 우선순위: P1.
- 구현 상태: 완료.

## 후속 기능

- 플랫폼별 OAuth 연결과 API adapter
- 게시 결과 callback, 재시도, 실패 사유
- 채널별 제목·설명 템플릿
- 썸네일 생성과 영상 상세 재생
