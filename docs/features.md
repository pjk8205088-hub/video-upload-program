# 동영상 업로드 프로그램 기능 목록

## 업로드 영역

- 목적: 동영상 파일을 빠르게 업로드한다.
- 사용자: 모든 로컬 워크스페이스 사용자.
- 입력: 파일 선택, 파일 드래그 앤 드롭.
- 처리: 확장자·크기 검증 후 `POST /api/videos`로 스트리밍 저장한다.
- 출력: 업로드 큐에 파일명과 진행률을 표시하고 완료 후 목록에 추가한다.
- 예외: 지원하지 않는 파일, 0바이트, 2 GB 초과, 서버 오류.
- 우선순위: P0.
- 구현 상태: 구현 완료.

## 업로드 진행률

- 목적: 업로드가 끝나기 전 현재 상태를 이해하게 한다.
- 사용자: 업로드를 시작한 사용자.
- 입력: XMLHttpRequest 업로드 이벤트.
- 처리: 전송된 바이트를 전체 바이트로 나누어 퍼센트로 변환한다.
- 출력: 진행률 바와 퍼센트를 표시한다.
- 예외: 길이를 알 수 없는 경우 상태 텍스트를 유지한다.
- 우선순위: P0.
- 구현 상태: 구현 완료.

## 내 동영상 목록

- 목적: 저장된 영상의 상태와 기본 정보를 확인한다.
- 사용자: 모든 로컬 워크스페이스 사용자.
- 입력: 목록 조회, 검색어, 정렬 토글.
- 처리: API 목록을 상태로 불러오고 클라이언트에서 필터·정렬한다.
- 출력: 파일명, 포맷, 용량, 상태, 생성 시각.
- 예외: 목록이 비어 있으면 첫 업로드를 유도하는 빈 상태를 표시한다.
- 우선순위: P0.
- 구현 상태: 구현 완료.

## 파일 검색 및 정렬

- 목적: 파일이 많아져도 원하는 파일을 찾는다.
- 사용자: 모든 로컬 워크스페이스 사용자.
- 입력: 파일명 검색어, 최신순/오래된순 토글.
- 처리: 원본 파일명 기준으로 부분 일치 필터를 적용한다.
- 출력: 검색·정렬된 목록.
- 예외: 결과가 없으면 빈 목록 상태를 유지한다.
- 우선순위: P1.
- 구현 상태: 구현 완료.

## 영상 삭제

- 목적: 불필요한 원본과 메타데이터를 제거한다.
- 사용자: 로컬 워크스페이스 관리자.
- 입력: 목록의 삭제 버튼, 확인 대화상자.
- 처리: `DELETE /api/videos/:id`가 파일과 메타데이터를 함께 제거한다.
- 출력: 목록 갱신 및 완료 토스트.
- 예외: 존재하지 않는 ID, 파일이 이미 사라진 경우.
- 우선순위: P1.
- 구현 상태: 구현 완료.

## 로컬 저장공간 표시

- 목적: 현재 등록된 영상의 대략적인 저장량을 알려준다.
- 사용자: 모든 로컬 워크스페이스 사용자.
- 입력: 목록의 파일 크기.
- 처리: 10 GB 기준으로 사용률을 계산한다.
- 출력: 사용량과 진행 바.
- 예외: 영상이 없으면 0 B, 0%를 표시한다.
- 우선순위: P1.
- 구현 상태: 구현 완료.

## 후속 기능

- 영상 상세 및 브라우저 재생
- 썸네일 추출
- 업로드 취소·재개
- 사용자 로그인과 역할별 권한
- 대용량 파일용 멀티파트 업로드
- 서버 측 포맷 변환·트랜스코딩
