# 동영상 업로드 프로그램 사용자 스토리

## US-001. 여러 SNS 계정 연결

As a 콘텐츠 운영자,
I want to 네이버·TikTok·Facebook·Instagram 계정을 연결하고 싶다,
So that 여러 채널을 한 프로그램에서 관리할 수 있다.

### 인수 조건

- [x] 플랫폼별 연결 카드가 보인다.
- [x] 계정 표시 이름과 핸들을 저장할 수 있다.
- [x] 연결된 계정을 해제할 수 있다.

## US-002. 하나의 영상 멀티 업로드

As a 영상 제작자,
I want to 하나의 영상을 여러 계정에 동시에 예약하고 싶다,
So that 같은 작업을 채널마다 반복하지 않을 수 있다.

### 인수 조건

- [x] 하나의 영상과 여러 계정을 선택할 수 있다.
- [x] 원본에서 각 계정으로 이어지는 연결 맵이 표시된다.
- [x] 계정별 `queued` 작업이 하나씩 생성된다.

## US-003. 예약일과 콘텐츠 정보 입력

As a 콘텐츠 운영자,
I want to 제목·설명·공개 범위·예약일을 한 번에 입력하고 싶다,
So that 모든 채널의 예약 작업을 일관되게 만들 수 있다.

### 인수 조건

- [x] 제목과 예약일 없이는 등록되지 않는다.
- [x] 설명과 공개 범위를 함께 저장한다.
- [x] 예약 큐에 대상 계정과 시간이 표시된다.

## US-004. Windows 프로그램으로 사용

As a 데스크톱 사용자,
I want to 웹페이지가 아닌 프로그램 창에서 사용하고 싶다,
So that 파일 업로드 도구처럼 빠르게 실행할 수 있다.

### 인수 조건

- [x] 앱 전용 타이틀바와 창 버튼이 있다.
- [x] 좌측 메뉴와 하단 상태바가 있다.
- [x] Electron 셸에서 화면과 로컬 서버를 함께 실행할 수 있다.
