# Upload Desk 요구사항

## 대상 사용자

영상 제작자, 1인 크리에이터, 여러 SNS 채널을 관리하는 소규모 브랜드 담당자.

## 핵심 사용자 흐름

1. 동영상 1~10개를 슬롯 보드에 저장한다.
2. SNS 계정을 연결한다.
3. 계정별 1~10 번호를 체크해 경로를 고른다.
4. AI 제목·설명·해시태그와 자동 썸네일을 확인한다.
5. 예약 시각을 지정하고 계정×슬롯 작업을 만든다.
6. 진행률·재시도·성공/실패 상태·로그를 확인한다.
7. 게시 후 통계와 댓글을 관리한다.

## 기능 요구사항

- FR-01: MP4, MOV, WebM, MKV를 지원하고 파일당 2 GB, 로컬 슬롯 최대 10개를 제한한다.
- FR-02: 영상은 1~10 고정 번호를 가지며 교체·삭제 시 관련 미게시 job을 취소한다.
- FR-03: 각 SNS 계정은 `slotNumbers` 배열을 가지며 체크 변경을 저장한다.
- FR-04: 예약 생성은 계정×슬롯 route마다 job을 만들고, 기존 게시·예약 조합은 중복 차단한다.
- FR-05: job은 진행률, 시도 횟수, 다음 재시도 시각, 마지막 오류, 로그를 가진다.
- FR-06: sandbox provider는 동시 게시, 통계, 댓글을 제공하고 실제 OAuth adapter 경계를 유지한다.
- FR-07: AI 키가 없을 때도 로컬 규칙 기반 제목·설명·해시태그가 생성된다.
- FR-08: 캘린더, 통계, 댓글 답글·숨김·해제, 활동 로그를 제공한다.
- FR-09: Electron에서 Windows 로그인 시작, 백그라운드 실행, 업데이트 확인을 제어한다.
- FR-10: 환경설정 아래에 Instagram, 네이버 클립, TikTok, Facebook별 로그인 페이지를 제공하고 provider별 OAuth callback 연결 지점을 분리한다.
- FR-11: TikTok 계정 연결과 업로드 경로 선택은 Facebook 계정이 연결된 경우에만 허용한다.

## 비기능 요구사항

- 서버 재시작 후 영상·계정·작업·설정이 유지된다.
- 비밀번호와 OAuth token은 현재 구현에 저장하지 않는다.
- 정적 파일 경로를 제한하고 업로드 파일명은 서버가 안전하게 정규화한다.
- 실제 외부 API 도입 시 token 암호화, rate limit, resumable upload, webhook 검증을 추가한다.
