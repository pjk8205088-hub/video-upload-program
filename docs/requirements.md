# 동영상 업로드 프로그램 요구사항

## 프로젝트 개요

동영상 파일을 한 곳에 보관하고 YouTube·네이버·TikTok·Facebook·Instagram 계정으로 동시에 예약 배포하는 Windows 데스크톱 작업공간이다. 앱은 로컬 HTTP 서버와 데스크톱 창으로 동작한다.

## 대상 사용자

영상 제작자, 콘텐츠 운영자, 1인 크리에이터, 여러 SNS 채널을 관리하는 소규모 브랜드 담당자.

## 핵심 흐름

1. 동영상 원본을 선택하거나 드래그 앤 드롭한다.
2. SNS 계정을 연결한다.
3. 원본과 대상 계정을 그래프형 연결 맵으로 확인한다.
4. 제목·설명·공개 범위·예약일을 입력한다.
5. YouTube 체크 항목을 자동으로 채우고 수동 확인 항목을 확인한다.
6. 여러 계정에 한 번에 예약 업로드 작업을 등록한다.

## 기능 요구사항

### FR-01. 동영상 업로드

- MP4, MOV, WebM, MKV를 지원한다.
- 1개 파일 최대 크기는 2 GB다.
- 파일 선택, 드래그 앤 드롭, 다중 선택을 지원한다.
- 업로드 진행률과 완료·실패 상태를 표시한다.

### FR-02. SNS 계정 관리

- YouTube, 네이버, TikTok, Facebook, Instagram을 지원한다.
- 플랫폼별 계정 표시 이름과 아이디·핸들을 저장한다.
- 계정별 연결 상태와 연결 해제를 제공한다.
- 비밀번호를 저장하지 않고 실제 배포에서는 OAuth를 사용한다.

### FR-03. 멀티 채널 연결

- 하나의 원본을 여러 계정에 연결할 수 있다.
- 선택된 계정마다 전송 작업이 생성된다.
- 화면에 영상 노드에서 각 계정 노드로 이어지는 거미줄형 연결선을 표시한다.

### FR-04. 예약 업로드

- 공통 제목, 설명·캡션, 공개 범위, 예약 날짜와 시간을 입력한다.
- 여러 계정을 동시에 선택한다.
- 예약 작업과 계정별 `queued` 상태를 저장한다.

### FR-05. YouTube 자동 체크

- 제목·설명·카테고리·공개 범위·태그 항목을 입력 상태로 자동 체크한다.
- 썸네일, 아동용 여부, 재생목록은 수동 확인으로 남긴다.
- 자동 체크 개수와 수동 체크 개수를 구분 표시한다.

### FR-06. 데스크톱 앱 창

- Windows 스타일 타이틀바를 제공한다.
- 최소화·최대화·닫기 버튼을 제공한다.
- Electron 셸이 로컬 API 서버를 실행하고 앱 화면을 로드한다.

## 비기능 요구사항

- 로컬 서버 재시작 후 동영상·계정·예약 작업이 유지된다.
- 키보드 포커스가 보인다.
- 데스크톱 창 크기에 맞게 패널이 재배치된다.
- 저장 파일명은 서버가 생성해 경로 조작을 방지한다.
- 실제 외부 SNS 전송 전에는 OAuth, 토큰 암호화, rate limit, 재시도 정책을 추가한다.

## 범위 외

실제 SNS API 게시, 썸네일 자동 생성, 영상 트랜스코딩, 팀 로그인, S3 업로드, 업로드 재개는 다음 단계에서 구현한다.
